# AGENTS.md — Benedictine Monastery of Thiên Hòa Fundraiser Website

## Project Overview

A static, 4-page Vietnamese website for the **Đan Viện Biển Đức Thiên Hòa** (Benedictine Monastery of Thiên Hòa) fundraiser to build a new chapel. Hosted on Firebase Hosting. No backend, no build step.

**Structure**: Each page is a standalone `.html` file with inline `<style>` / `<script>`. Navigation bar and footer are **loaded dynamically** via `assets/js/components.js` — each page uses `<div id="navbar-placeholder">` and `<div id="footer-placeholder">` with a `<script>var currentPage="pagename";</script>` declaration before the components.js include. Only one source of truth for nav/footer markup.

**Tech Stack**: Bootstrap 5.3.8 + Bootstrap Icons 1.13.1 (CDN), Google Fonts (Lora + Inter), vanilla JavaScript (no framework). All custom CSS is in `assets/css/custom.css`.

| File | Route | Purpose |
|------|-------|---------|

## Essential Commands

| Action | Command |
|--------|---------|
| **Local preview** | Any static file server: `python3 -m http.server 8080` or `npx serve .` (opens root — `index.html`) |
| **Deploy** | `firebase deploy --project staging` |
| **Deploy staging** | `firebase deploy --project thien-hoa-monastery-placeholder` (default) |
| **Deploy production** | `firebase deploy --project vn-fund-dvbdth` |

**No build tool, no package.json, no test framework.** The site is served directly from the repository root.

## Data Flow & Client-Side Architecture

All dynamic data is fetched client-side via `fetch()` on DOMContentLoaded:

1. **`tiendo.html`** fetches `assets/data/schedule.json` → renders Bootstrap table + fetches `assets/data/gallery.json` → renders CSS timeline with Bootstrap modal lightbox
2. **`donggop.html`** fetches `assets/data/donations.csv` → parses with custom CSV parser → renders paginated/sortable/filterable table. Falls back to warning alert if CSV missing/empty

No server-side rendering, no build-time data injection. All data requests happen in the browser.

## Scripts

### `scripts/update-gallery.sh`

Scans `assets/images/progress/` for `.jpg`/`.jpeg`/`.png` files, extracts dates from filenames (YYYY-MM-DD pattern), generates `gallery.json`. Run when adding new progress photos:

```bash
bash scripts/update-gallery.sh
```

### `scripts/convert-assets.py`

Reads Excel files (`.xlsx`/`.xls`) from `raw_assets/` or project root. Auto-detects donation sheets (by Vietnamese column headers like "Ngày", "Tên", "Số tiền", "Ghi chú") and schedule sheets (by "Giai đoạn", "Nội dung công việc"). Outputs `donations.csv` and `schedule.json`.

**Requires pandas:** `pip install pandas openpyxl`

Run:
```bash
python3 scripts/convert-assets.py
```

## Gotchas & Conventions

- **Navbar & Footer templating**: Navbar and footer are loaded dynamically by `assets/js/components.js`. Each page has `<div id="navbar-placeholder">` and `<div id="footer-placeholder">` with a `<script>var currentPage="pagename";</script>` before the components.js include. Edit `components.js` to update nav/footer markup in one place. The page-specific `currentPage` value controls which nav link gets the `active` class.
- **`assets/js/components.js` order**: Must come BEFORE Bootstrap JS bundle so the navbar/footer DOM is available for Bootstrap's navbar-collapse toggle. The current order is: `components.js` → Bootstrap bundle.
- **CSV is parsed client-side**: `donggop.html` includes a custom CSV parser (handles quoted fields, multi-line). The CSV format is: `date,name,amount,note` (header row required).
- **Date format**: All JSON data uses `YYYY-MM-DD` format. Display converts to `DD/MM/YYYY` client-side.
- **Asset paths**: Some links in `index.html` sidebar use absolute paths (`/assets/docs/...`), while others use relative paths. Be consistent when adding new links.
- **CORS note**: Firebase clean URLs means visiting `/donggop` serves `donggop.html`. Asset references via `fetch()` use relative paths (`assets/data/...`).
- **No SPA routing**: Page navigation is full-page reload. No client-side router.
- **Vietnamese language**: All UI text is Vietnamese (vi). Commit messages and code comments are in English.
- **No form submission**: The donation page shows bank details + QR code only — no payment form. Donations happen externally via Vietcombank.
- **Logo is a PNG (Saint Benedict Medal)**: Loaded in navbar at 55x55px with `object-fit: contain`.
- **Skills & agents config**: The `.agents/` directory contains agent skill definitions (not part of the actual site). The `.old.DESIGN.md` is an archived earlier design spec; `DESIGN.md` is the active one.
- **No CI/CD pipeline**: Deploy is manual via `firebase deploy`.
- **No package-lock.json generated**: The `.gitignore` explicitly ignores it. No npm/yarn used at all.
